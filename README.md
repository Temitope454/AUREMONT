# Auremont 

A global property-discovery and transaction platform.

## Getting Started

To run the development server locally:

```bash
cd C:\Users\User\.gemini\antigravity-ide\scratch\auremont
npm install
npm run dev
```

## Structure
- The `src/index.css` file implements the comprehensive design system, color tokens, and typograpical foundations.
- `src/App.tsx` handles routing.
- The `src/pages/Home.tsx` contains the cinematic homepage, showcasing the curated property feed and primary search composer.
- High-quality architectural mock images are included in the `public/images` folder.
